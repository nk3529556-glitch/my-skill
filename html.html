👋 HTML कोर्स में आपका स्वागत है

इस पेज पर आप HTML को आसान हिंदी में सीखेंगे। हर विषय में टैग का काम, उदाहरण और जरूरी जानकारी दी गई है।

ध्यान दें: यह HTML सीखने की शुरुआती सामग्री है। सभी HTML टैग और उनके नियम सीखने के लिए आगे के अध्याय भी पढ़ें।

अध्याय 1: HTML क्या है?

HTML का पूरा नाम HyperText Markup Language है। इसका उपयोग वेब पेज की संरचना बनाने के लिए किया जाता है।

HTML का उपयोग कहाँ होता है?

  • वेब पेज का शीर्षक बनाने में।
  • पैराग्राफ और टेक्स्ट दिखाने में।
  • चित्र और लिंक जोड़ने में।
  • सूची, टेबल और फॉर्म बनाने में।
  • वेब पेज की मूल संरचना तैयार करने में।
महत्वपूर्ण: HTML एक Markup Language है, Programming Language नहीं। CSS से पेज को सजाया जाता है और JavaScript से उसमें व्यवहार और इंटरैक्टिव सुविधाएँ जोड़ी जाती हैं।

अध्याय 2: HTML का बेसिक ढाँचा

एक सामान्य HTML5 पेज का उदाहरण नीचे दिया गया है:

<!DOCTYPE html>
<html lang="hi">
<head>
    <meta charset="UTF-8">
    <meta name="viewport"
          content="width=device-width, initial-scale=1.0">
    <title>मेरा पहला पेज</title>
</head>
<body>
    <h1>नमस्ते दुनिया!</h1>
    <p>यह मेरा पहला वेब पेज है।</p>
</body>
</html>

हर भाग का काम

  • <!DOCTYPE html> — ब्राउज़र को HTML5 दस्तावेज़ बताता है।
  • <html> — HTML दस्तावेज़ का मूल तत्व है।
  • <head> — पेज की जानकारी रखता है।
  • <meta> — कैरेक्टर सेट और अन्य मेटाडेटा बताता है।
  • <title> — ब्राउज़र टैब का शीर्षक निर्धारित करता है।
  • <body> — पेज पर दिखाई देने वाली मुख्य सामग्री रखता है।
  • <h1> — मुख्य स्तर का शीर्षक बनाता है।
  • <p> — पैराग्राफ बनाता है।

अध्याय 3: टैग और एलिमेंट क्या हैं?

टैग: HTML में कोणीय ब्रैकेट के अंदर लिखे जाने वाले निर्देश, जैसे <p>।

एलिमेंट: आम तौर पर शुरुआती टैग, सामग्री और अंतिम टैग मिलकर एक एलिमेंट बनाते हैं। 

<p>यह एक पैराग्राफ है।</p>
  • <p> — शुरुआती टैग।
  • यह एक पैराग्राफ है। — सामग्री।
  • </p> — अंतिम टैग।

कुछ HTML तत्व खाली होते हैं और उनका अलग अंतिम टैग नहीं होता, जैसे <br> और <img>।

अध्याय 4: HTML टैग की सूची

नीचे जरूरी टैग दिए गए हैं। खोज बॉक्स में टैग का नाम या उसका काम लिखकर संबंधित टैग खोज सकते हैं।

<h1> से <h6>

छह स्तर के शीर्षक बनाने के लिए।

<h1>मुख्य शीर्षक</h1>
<h2>दूसरा शीर्षक</h2>
<h3>तीसरा शीर्षक</h3>

<p>

पैराग्राफ बनाने के लिए।

<p>मेरा पहला पैराग्राफ।</p>
<p>दूसरा पैराग्राफ।</p>

<br>

लाइन बदलने के लिए।

श्याम

<hr>
<p>दूसरा विषय</p>

<strong>

महत्वपूर्ण टेक्स्ट दर्शाने के लिए।

<b>

<b>बोल्ड टेक्स्ट</b>

<i>

टेक्स्ट को इटैलिक रूप में दिखाने के लिए।

<i>इटैलिक टेक्स्ट</i>

<u>

टेक्स्ट के नीचे रेखा दिखाने के लिए।

<u>रेखांकित टेक्स्ट</u>

<mark>

टेक्स्ट को हाइलाइट करने के लिए।

<mark>जरूरी शब्द</mark>

<small>

छोटे टेक्स्ट के लिए।

<small>छोटा टेक्स्ट</small>

<del>

<del>पुरानी कीमत</del>

<ins>

जोड़े गए टेक्स्ट को दर्शाने के लिए।

<sup>

</a>

<ul>

  <li>आम</li>
</ul>

<ol> और <li>

<ol>
  <li>पहला</li>
  <li>दूसरा</li>
</ol>

<div>

सामग्री को समूह में रखने के लिए।

  <h2>शीर्षक</h2>
  <p>जानकारी</p>
</div>

  <input id="name" type="text">
  <button type="submit">

<input>

<main>
  <h2>मुख्य जानकारी</h2>

<section>
  <h2>हमारे कोर्स</h2>
</section>

<article>

स्वतंत्र लेख या सामग्री के लिए।

<article>
  <h2>HTML क्या है?</h2>
  <p>HTML वेब पेज बनाता है।</p>
</article>

<aside>

सहायक या अतिरिक्त सामग्री के लिए।

<aside>
  अतिरिक्त जानकारी
</aside>

<footer>

पेज या भाग के निचले हिस्से के लिए।

<footer>
  कॉपीराइट जानकारी
</footer>

<details> और <summary>

खुलने-बंद होने वाला अतिरिक्त विवरण बनाने के लिए।

<details>
  <summary>उत्तर देखें</summary>
  HTML एक Markup Language है।
</details>

<pre> और <code>

कोड या पहले से व्यवस्थित टेक्स्ट दिखाने के लिए।

<pre>
  <code>let x = 10;</code>
</pre>

यह सूची शुरुआती और सामान्य रूप से उपयोग होने वाले टैगों की है, HTML के हर टैग की संपूर्ण सूची नहीं।

अध्याय 5: HTML का अभ्यास

उदाहरण 1: अपना परिचय

<!DOCTYPE html>
<html lang="hi">
<head>
  <meta charset="UTF-8">
  <title>मेरा परिचय</title>
</head>
<body>
  <h1>मेरा नाम राहुल है।</h1>
  <p>मैं HTML सीख रहा हूँ।</p>
</body>
</html>

उदाहरण 2: लिंक बनाना

<a href="https://example.com">
  वेबसाइट खोलें
</a>

उदाहरण 3: सूची बनाना

<h2>मेरे विषय</h2>
<ul>
  <li>हिंदी</li>
  <li>अंग्रेजी</li>
  <li>कंप्यूटर</li>
</ul>

उदाहरण 4: टेबल बनाना

<table border="1">
  <tr>
    <th>नाम</th>
    <th>कक्षा</th>
  </tr>
  <tr>
    <td>राम</td>
    <td>10</td>
  </tr>
</table>

वास्तविक वेबसाइटों में टेबल की सजावट के लिए CSS का उपयोग करना बेहतर रहता है।

अध्याय 6: HTML के जरूरी नियम

  1. HTML टैग सही क्रम में लिखें।
  2. जिन टैगों का समापन जरूरी है, उन्हें बंद करें।
  3. एट्रिब्यूट की वैल्यू उद्धरण चिह्नों में लिखें।
  4. चित्र के लिए उपयोगी alt टेक्स्ट दें।
  5. पेज में एक स्पष्ट मुख्य शीर्षक रखें।
  6. HTML की संरचना और CSS की सजावट को समझें।
  7. कोड लिखने के बाद ब्राउज़र में जाँच करें।

अध्याय 7: HTML प्रश्नोत्तरी

सही उत्तर चुनें और अपना टेस्ट पूरा करें।

1. HTML का पूरा नाम क्या है?

2. पैराग्राफ के लिए कौन-सा टैग है?

3. चित्र दिखाने के लिए कौन-सा टैग है?

4. लिंक बनाने के लिए कौन-सा टैग है?

5. HTML का मुख्य उपयोग क्या है?

📚 आगे क्या सीखना चाहिए?

  1. HTML के सभी टेक्स्ट और फॉर्मेटिंग टैग।
  2. लिंक, इमेज और मीडिया टैग।
  3. टेबल और लिस्ट।
  4. फॉर्म, इनपुट और बटन।
  5. Semantic HTML और Accessibility।
  6. CSS से वेबसाइट को सजाना।
  7. JavaScript से वेबसाइट को इंटरैक्टिव बनाना।
यह शुरुआती कोर्स है। HTML के सभी मानक तत्वों, विशेषताओं, फॉर्म नियंत्रणों और उन्नत विषयों के लिए आगे के अध्याय जोड़ना जरूरी होगा।
